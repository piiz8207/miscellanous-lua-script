# Miscellaneous Lua Scripts for Aegisub

A personal collection of experimental, ad-hoc, and utility Lua automation scripts developed for Aegisub workflows. 

> [!WARNING]
> Most scripts here were built on the fly to address immediate typesetting and localization tasks. Code quality is experimental, edge cases may exist, and many scripts still require cleanup or refactoring. Use with care and test on backup `.ass` files first.
